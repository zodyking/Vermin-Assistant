# Vermin Assistant

Plays a built-in high-frequency deterrent on Home Assistant media players.

## Controls

- **Speakers.** Players that can play audio.
- **Schedule.** Hours, away, or both. An overnight range continues past midnight. The same hour for both means all day. The hour repeats while the schedule is on.
- **Sound.** Mouse 92 kHz, rat 76 kHz, cockroach 3 kHz, cricket 100 kHz, mosquito 2 kHz, moth 80 kHz. **Demo** plays on this computer. **Play** uses the selected speakers.

Volume is applied when the player accepts it. The tone replaces what that speaker was playing for the pass.

The add-on generates the hour. It is not a copy of the YouTube clip “Mouse & Rat Ultrasonic Deterrent”.
